# baduk

Python(Tkinter)으로 만든 2인 로컬 대국용 바둑 프로그램입니다. 19줄 정식 규칙(착수, 따내기,
자살수 금지, 패(ko) 규칙, 계가)을 지원합니다.

## 실행 방법

```
python main.py
```

별도 설치가 필요한 외부 라이브러리는 없습니다 (Python 표준 라이브러리 tkinter만 사용).

실행하면 **2인 로컬 대국**과 **프로 기보 훈련(SGF 복기)** 중 선택하는 메뉴가 뜹니다.

## 2인 로컬 대국

- 좌클릭으로 착수합니다.
- **착수 포기 (Pass)**: 두 사람이 연속으로 포기하면 대국이 종료되고 계가 단계로 넘어갑니다.
- **한 수 무르기**: 직전 상태로 되돌립니다.
- **기권**: 즉시 상대 승리로 대국을 종료합니다.
- 계가 단계에서는 죽은 돌을 클릭해 표시(빨간 X)한 뒤 **계가 확정**을 누르면 결과가 표시됩니다.
  실수로 넘어왔다면 **대국 재개**로 되돌아갈 수 있습니다.
- 집계산은 중국식 면적 계산(돌 수 + 집)을 사용하며 덤은 6.5집입니다.

## 프로 기보 훈련 (SGF 복기)

- **SGF 불러오기**로 `.sgf` 기보 파일을 엽니다. 테스트용 예제가 `samples/example.sgf`에 있습니다.
- 처음/이전/다음/끝 버튼과 슬라이더로 원하는 수까지 자유롭게 이동하며 복기할 수 있습니다.
- 돌 위에 수순 번호가 표시되고, 기보에 코멘트가 있으면 하단에 함께 표시됩니다.
- **퀴즈 모드**를 켜면 다음 수를 직접 클릭해 맞혀야 합니다. 대상(전체/흑/백)을 지정하면 그 색의
  차례에만 문제가 나오고 나머지는 자동으로 넘어갑니다. 정답/오답과 누적 정답률이 표시됩니다.
- 변화도(수순 분기)가 있는 SGF는 본선(main line)만 재생하며, 변화도는 무시합니다.
- 배석/핸디캡(AB/AW, HA)을 인식하며, 인코딩은 UTF-8/CP949/Latin-1을 자동으로 시도합니다.

## AI 문제 자동 생성 (KataGo 연동)

`generate_quiz.py`는 SGF 기보를 KataGo 분석 엔진(Analysis Engine)에 돌려서,
각 수마다 KataGo의 최선수를 찾아 문제 SGF를 자동 생성합니다. 생성된 SGF는
그대로 위의 **프로 기보 훈련** 화면에서 불러와 퀴즈 모드로 풀 수 있습니다
(퀴즈 정답 = 실제로 두어진 수가 아니라 KataGo가 추천한 수).

```
python generate_quiz.py --sgf samples/example.sgf --out samples/example_quiz.sgf
```

기본값은 `threshold=0`으로, 매 수마다 KataGo 최선수로 대체합니다(대체된 수를
기준으로 다음 수를 이어서 분석하므로 결과 기보는 항상 합법적인 한 줄 수순입니다).
`--threshold`를 높이면 실제 수와 KataGo 최선수의 승률차가 그 값(%p) 이상 나는
"실수 지점"에서만 대체하고 나머지는 실제 수를 그대로 둡니다.

주요 옵션:

- `--visits N`: 수당 분석 방문수 (기본 600). 클수록 정확하지만 느립니다.
- `--color {all,B,W}`: 어느 색의 수만 문제로 만들지 (기본 all).
- `--start N --end N`: 분석할 수순 범위(1부터, 포함).
- `--threshold N`: 대체 기준 승률차(%p). 0 = 전체 수순 문제화.
- `--katago / --model / --katago-config`: KataGo 실행파일/모델/설정 경로
  (기본값은 `C:\baduk\lizzie\katago_cuda.exe` + `KataGo28b.gz`).

전체 게임을 기본 설정(600 visits)으로 돌리면 수당 몇 초씩 걸리므로, 긴 기보는
`--start/--end`나 `--visits`를 낮춰 먼저 일부만 테스트해 보는 것을 권장합니다.

주의: 이 방식은 한 수를 AI 추천수로 바꾸면 그 다음부터는 "바뀐 수를 기준으로"
이어서 분석하기 때문에, 대체가 몇 번 일어나면 실제 프로 경기와는 다른 흐름이
됩니다. 실전 흐름을 그대로 유지하면서 "진짜 실수한 곳"만 문제로 만들고 싶다면
`--threshold`를 충분히 높게 주세요.

### 설정 파일로 문제 만들기 (`make_quiz.py` + `quiz_config.ini`)

매번 긴 명령줄 옵션을 치기 귀찮으면 `quiz_config.ini` 파일을 열어서 값만 바꾸고
아래처럼 실행하면 된다.

```
python make_quiz.py
```

`quiz_config.ini`에서 바꿀 수 있는 값:

- `기보경로`: 기보 파일 하나 또는 기보들이 들어있는 폴더
- `출력폴더`: 문제 SGF를 저장할 폴더
- `문제개수`: 만들 문제 수
- `난이도`: 쉬움/보통/어려움 (또는 숫자로 승률차 %p 직접 지정)
- `정답포함`: 예(우리 프로그램용, 자동 퀴즈 모드) / 아니오(LizzieYzy 등에서 직접 풀 때)
- `색`, `최소수순`, `최대수순`, `분석강도`, `시드`, KataGo 경로들

다른 설정 파일을 쓰려면 `python make_quiz.py 다른설정.ini`처럼 경로를 인자로 준다.

### 기보에서 장면을 무작위로 뽑아 문제 만들기 (`generate_random_quiz.py`)

기보 하나에서 국면을 무작위로 여러 개 뽑아, 각 장면마다 "여기서 KataGo가 1등으로
추천하는 수는?"을 묻는 문제 SGF를 장면 하나당 파일 하나씩 만듭니다. 위
`generate_quiz.py`와 달리 실전 수순을 전혀 건드리지 않고, 실제 국면(캡처까지
정확히 반영)을 그대로 스냅샷 떠서 문제로 만들기 때문에 원본 기보가 왜곡되지
않습니다.

```
python generate_random_quiz.py --sgf samples/example.sgf --out-dir samples/example_scenes --count 10
```

생성된 각 SGF 파일은 "프로 기보 훈련" 화면에서 그대로 불러오면 됩니다 (돌 배치가
문제 국면이고, 첫 클릭이 정답 확인).

주요 옵션:

- `--count N`: 만들 문제 개수 (기본 10)
- `--color {all,B,W}`: 어느 색 차례의 장면만 뽑을지
- `--min-move / --max-move`: 장면을 뽑을 수순 범위 (예: 초반 포석은 제외하고 싶으면 `--min-move 30`)
- `--seed N`: 같은 시드면 항상 같은 장면이 뽑힘 (재현용)
- `--visits`, `--katago / --model / --katago-config`: 위와 동일

## 구조

- `go/board.py`: 규칙 엔진(착수, 따내기, 패, 집계산)
- `go/render.py`: 바둑판 렌더링 공통 유틸 (대국/복기 화면 공유)
- `go/gui.py`: 2인 대국 GUI
- `go/sgf.py`: SGF 파서
- `go/sgfwrite.py`: SGF 직렬화(쓰기) 유틸
- `go/katago.py`: KataGo 분석 엔진(Analysis Engine) 연동 래퍼
- `go/replay.py`: SGF 기보를 규칙 엔진으로 재생하는 유틸
- `go/kifu_gui.py`: 기보 훈련(복기/퀴즈) GUI
- `generate_quiz.py`: KataGo 분석으로 실전 수순을 AI 추천수로 대체해 문제 SGF를 만드는 CLI 스크립트
- `generate_random_quiz.py`: 기보에서 장면을 무작위로 뽑아 장면별 "1등 수 찾기" 문제 SGF를 만드는 CLI 스크립트
- `make_quiz.py` / `quiz_config.ini`: 명령줄 옵션 대신 설정 파일로 문제를 생성하는 진입점
- `samples/example.sgf`: 테스트용 예제 기보
- `main.py`: 실행 진입점 (모드 선택 메뉴)
